นโยบายความเป็นส่วนตัว — น้องกระปุก (Nong Krapook)

ปรับปรุงล่าสุด: 24 พฤศจิกายน 2569

แอป "น้องกระปุก" เป็นแอปบันทึกรายรับ-รายจ่ายส่วนบุคคล พัฒนาโดยผู้พัฒนารายบุคคล นโยบายนี้อธิบายว่าแอปเก็บ ใช้ และจัดการข้อมูลของคุณอย่างไร

1. ข้อมูลที่แอปเก็บ และเก็บไว้ที่ไหน

แอปนี้ทำงานแบบ เก็บข้อมูลในเครื่องของคุณเท่านั้น (offline-first) ข้อมูลรายรับ-รายจ่าย บัญชี หมวดหมู่ หนี้/เงินยืม รายการประจำ และการตั้งค่าทั้งหมด จะถูกบันทึกเป็นไฟล์ในเครื่องของคุณเพียงที่เดียว เราไม่มีเซิร์ฟเวอร์ที่เก็บข้อมูลเหล่านี้ และไม่ส่งข้อมูลธุรกรรมของคุณออกไปที่ใดโดยไม่ได้รับความยินยอม

ถ้าคุณลบแอป ข้อมูลทั้งหมดในเครื่องจะหายไปด้วย เนื่องจากไม่มีสำเนาสำรองบนคลาวด์ในเวอร์ชันปัจจุบัน

2. สิทธิ์ที่แอปขอ และเหตุผล

  • เข้าถึงรูปภาพ (Photos/Media) — ใช้สำหรับฟีเจอร์อ่านสลิปธนาคารอัตโนมัติ แอปจะสแกนเฉพาะโฟลเดอร์อัลบั้มที่คุณระบุว่าเป็นแอปธนาคาร (เช่น K PLUS, SCB EASY) เพื่อหารูปสลิปใหม่ที่ยังไม่เคยประมวลผล — ไม่ได้อ่านหรืออัปโหลดรูปภาพอื่นในเครื่องของคุณ
  • การแจ้งเตือน (Notifications) — ใช้เตือนรายการที่ต้องจ่ายวันนี้ รายการประจำ และภาษี ทำงานในเครื่องทั้งหมด ไม่มีการส่งข้อมูลออกไปนอกเครื่อง
  • การเข้าถึงการแจ้งเตือน (Notification access) — เฉพาะ Android และเฉพาะเมื่อคุณเปิดฟีเจอร์ "จดจากแจ้งเตือนธนาคาร" เอง — ใช้จดรายการเงินเข้า-ออกให้อัตโนมัติจากแจ้งเตือนของแอปธนาคาร (ดูข้อ 2.1) แอปจะแสดงคำอธิบายก่อน แล้วให้คุณเปิดสิทธิ์เองในหน้าตั้งค่าของระบบ ปิดได้ทุกเมื่อทั้งในแอปและในตั้งค่าระบบ
  • อินเทอร์เน็ต — ใช้เฉพาะตอนคุณเลือกอ่านสลิปด้วย Typhoon API (ดูข้อ 3) และตอนเปิดลิงก์ภายนอก (เช่น ลิงก์สร้าง API key)

2.1 จดจากแจ้งเตือนธนาคาร

  • อ่านเฉพาะแจ้งเตือนจากแอปธนาคาร/บัตร/กระเป๋าเงินที่รองรับ ได้แก่ K PLUS, MAKE by KBank, Krungthai NEXT, เป๋าตัง, SCB EASY, Bualuang mBanking, KMA กรุงศรี, ttb touch, MyMo, BAAC Mobile, GHB ALL GEN, UOB TMRW, CIMB THAI, LHB You, KKP Better, Dime!, TISCO My Wealth, ICBC Mobile, KTC Mobile, UCHOOSE, CardX, AEON THAI MOBILE, TrueMoney และข้อความใน LINE / SMS เฉพาะที่ชื่อผู้ส่งเป็นธนาคาร — แจ้งเตือนจากแอปอื่นและแชตส่วนตัวถูกข้ามโดยไม่เก็บ
  • ข้อความ OTP / รหัสยืนยัน ถูกข้ามและไม่ถูกเก็บ
  • แอปดึงเฉพาะยอดเงิน ทิศทาง (เข้า/ออก) เลขท้ายบัญชี และเวลา เพื่อสร้างรายการ — ข้อความแจ้งเตือนที่ใช้ ถูกเก็บในไฟล์ข้อมูลในเครื่องของคุณ (ไว้กันบันทึกซ้ำ) และถูกลบเมื่อคุณล้างข้อมูลหรือถอนแอป
  • ประมวลผลในเครื่อง — ยกเว้นกรณีเดียว: ถ้าคุณเลือกอ่านสลิปด้วย Typhoon API อยู่ และแอปอ่านข้อความแจ้งเตือนจากแอปธนาคารบางข้อความไม่ออก แอปจะส่งเฉพาะข้อความแจ้งเตือนนั้น ไปให้ Typhoon (ข้อ 3) ช่วยแยกยอดเงิน — ถ้าใช้โหมดอ่านในเครื่อง จะไม่มีการส่งใดๆ

3. บริการจากบุคคลที่สาม (Third-Party Service)

แอปมีวิธีอ่านสลิป 2 แบบ ให้คุณเลือกได้ทีละแบบในหน้าอ่านสลิป:

  • อ่านในเครื่อง — ใช้โมเดลอ่านข้อความที่ติดมากับแอป (OpenThai OCR) ทำงานในเครื่องทั้งหมด ไม่ส่งรูปหรือข้อมูลใดออกจากเครื่อง
  • Typhoon API — ใช้ได้เมื่อคุณตั้งค่า API key ของคุณเองเท่านั้น แอปจะส่ง เฉพาะรูปสลิปที่คุณเลือก/ที่ตรวจพบในอัลบั้มธนาคาร ไปยัง Typhoon API (บริการของ SCB 10X) เพื่อแปลงรูปเป็นข้อความ แล้วส่งข้อความที่ได้ พร้อมรายชื่อหมวดหมู่ในแอปของคุณ ให้ AI ของ Typhoon ช่วยตรวจทานยอด/วันที่และเลือกหมวด รวมถึงข้อความแจ้งเตือนธนาคารที่อ่านไม่ออกตามข้อ 2.1 — ไม่ส่งประวัติธุรกรรมหรือข้อมูลอื่นในแอป

กรุณาอ่านนโยบายความเป็นส่วนตัวของ Typhoon เพิ่มเติมได้ที่เว็บไซต์ของผู้ให้บริการ

4. โฆษณาและการวิเคราะห์ข้อมูล (Ads & Analytics)

แอปเวอร์ชันปัจจุบันไม่มีโฆษณา ไม่มีระบบวิเคราะห์พฤติกรรมผู้ใช้ (analytics/tracking) และไม่มีการเก็บข้อมูลส่วนบุคคลเพื่อการตลาด

5. บัญชีผู้ใช้และการซิงก์ข้ามอุปกรณ์

เวอร์ชันปัจจุบันยังไม่มีระบบสมัครสมาชิก/เข้าสู่ระบบ และยังไม่รองรับการซิงก์ข้อมูลข้ามอุปกรณ์ หากในอนาคตมีการเพิ่มฟีเจอร์นี้ เราจะปรับปรุงนโยบายนี้และแจ้งให้ทราบล่วงหน้าก่อนเปิดใช้งาน

6. การลบข้อมูล

เนื่องจากข้อมูลทั้งหมดอยู่ในเครื่องของคุณเท่านั้น การลบข้อมูลทำได้โดย:

  • ใช้ฟีเจอร์ "ล้างข้อมูลทั้งหมด" ภายในแอป (หน้าตั้งค่า) หรือ
  • ถอนการติดตั้งแอปออกจากเครื่อง

7. การเปลี่ยนแปลงนโยบายนี้

เราอาจปรับปรุงนโยบายนี้เป็นระยะเพื่อให้ตรงกับฟีเจอร์ใหม่ของแอป (เช่น การซิงก์คลาวด์ในอนาคต) วันที่ปรับปรุงล่าสุดจะแสดงไว้ด้านบนของหน้านี้เสมอ
