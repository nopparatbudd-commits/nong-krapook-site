# น้องกระปุก 🐷 แอปจดรายรับ-รายจ่ายภาษาไทย

![Cover](cover.png)

## เกี่ยวกับแอป

**น้องกระปุก** (Nong Krapook) เป็นแอปพลิเคชันสำหรับจดบันทึกรายรับและรายจ่ายของคุณ ที่ออกแบบมาอย่างเรียบง่ายและเป็นมิตรกับผู้ใช้ภาษาไทย 

แอปนี้เป็นโปรเจกต์ส่วนบุคคล พัฒนาโดยนักพัฒนาแต่ละคน โดยมุ่งเน้นการให้ความสำคัญกับ **ความเป็นส่วนตัว** และ **ความปลอดภัยของข้อมูล** ของผู้ใช้

## ✨ ฟีเจอร์หลัก

- 📊 **จดรายรับ-รายจ่าย** - บันทึกรายการธุรกรรมของคุณได้อย่างง่ายดาย
- 💰 **จัดการบัญชี** - สร้างและจัดการบัญชีเงินต่างๆ
- 🏷️ **หมวดหมู่** - จัดหมวดหมู่รายการของคุณเพื่อการจัดการที่ดีขึ้น
- 💳 **ติดตามหนี้เงินยืม** - บันทึกหนี้และเงินยืมของคุณ
- 🔄 **รายการประจำ** - สร้างรายการที่ซ้ำๆ กันเพื่อประหยัดเวลา
- 📱 **อ่านสลิปอัตโนมัติ** - สแกนและแปลงรูปสลิปธนาคารเป็นข้อมูล (ใช้ Typhoon OCR API)
- 🔔 **แจ้งเตือน** - เตือนเกี่ยวกับรายการที่ต้องจ่าย รายการประจำ และกำหนดเวลาภาษี
- 🎯 **ตั้งค่าตามต้องการ** - ปรับแต่งแอปให้เหมาะกับความต้องการของคุณ

## 🔒 ความเป็นส่วนตัวและความปลอดภัย

### การเก็บข้อมูล (Offline-First)
- ✅ **ข้อมูลทั้งหมดถูกเก็บในเครื่องของคุณเท่านั้น** - ไม่มีเซิร์ฟเวอร์
- ✅ **ไม่มีการส่งข้อมูลออกไป** - เราไม่ส่งข้อมูลธุรกรรมของคุณไปที่ใดนอกจากกรณีที่คุณเลือกใช้ฟีเจอร์ OCR
- ✅ **ไม่มีโฆษณา** - แอปไม่มีโฆษณาหรือการติดตามข้อมูลผู้ใช้
- ✅ **ไม่มีการวิเคราะห์พฤติกรรม** - ไม่มีการเก็บข้อมูลสำหรับการตลาด

### สิทธิ์ที่ขอ
- **เข้าถึงรูปภาพ** - เพื่อสแกนสลิปธนาคารจากรูปภาพที่คุณเลือก
- **การแจ้งเตือน** - เพื่อส่งการแจ้งเตือนในเครื่อง
- **อินเทอร์เน็ต** - เฉพาะเมื่อคุณใช้ฟีเจอร์ OCR หรือเปิดลิงค์ภายนอก

## 🔗 บริการจากบุคคลที่สาม

เมื่อคุณใช้ฟีเจอร์ **อ่านสลิปอัตโนมัติ** แอปจะส่งรูปสลิปเท่านั้น ไปยัง:
- **Typhoon OCR API** (บริการของ SCB 10X) - เพื่อแปลงรูปภาพเป็นข้อความ
- คุณต้องตั้งค่า API key ของคุณเองก่อนใช้ฟีเจอร์นี้

## 📋 ข้อมูลในเครื่อง

แอปเก็บข้อมูลเหล่านี้ในเครื่องของคุณ:
- รายการรายรับและรายจ่าย
- ข้อมูลบัญชี
- หมวดหมู่
- หนี้และเงินยืม
- รายการประจำ
- การตั้งค่าแอป

## 🗑️ การลบข้อมูล

คุณสามารถลบข้อมูลทั้งหมดได้โดย:
1. ใช้ฟีเจอร์ "ล้างข้อมูลทั้งหมด" ในหน้าตั้งค่าของแอป หรือ
2. ถอนการติดตั้งแอปออกจากเครื่องของคุณ
